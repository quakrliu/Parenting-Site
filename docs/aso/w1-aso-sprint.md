## 1. App Store Subtitle 候選（限 30 字）

**現況**：`AI 智慧育兒｜成長發展追蹤`（14 字，太通用）

| 選項 | 文案 | 字數 | 強項 |
|---|---|---|---|
| **A** ⭐ | 蒙特梭利 AI 育兒｜0-18 歲 | 14 | **蒙特梭利**＋**AI**＋**0-18 歲**全到位 |
| B | 0-18 歲蒙特梭利｜AI 育兒夥伴 | 15 | 強調夥伴感，較柔軟 |
| C | AI 蒙特梭利導師｜每日成長任務 | 15 | 強調 daily task feature |
| D | 蒙特梭利 × AI｜0-18 歲全程陪伴 | 16 | 視覺對比 × 符號吸睛 |
| E | 蒙特梭利育兒｜AI 親子日記 | 13 | 親子日記＝記錄＋日常感 |

**推薦 A**：3 個高搜尋詞（蒙特梭利、AI、0-18 歲）全進、字數短、唸起來順。

## 3. App Store Keywords（隱藏欄位，限 100 字符，逗號分隔）

**草稿**：
```
育兒,蒙特梭利,親子,AI,正向教養,寶寶,幼兒,發展,成長,教養,新手爸媽,Montessori,parenting,toddler
```
（96 字符）

**策略**：
- 高搜尋量：育兒、親子、寶寶、幼兒、教養
- 差異化：蒙特梭利、正向教養、AI、發展
- 雙語：中英文都放，撈跨語家庭
- 避免重複 App name / Subtitle 的字（Apple 演算法不重複計算）

## 4. Developer Name 改名建議

**現況**：`YuKai Liu`（個人名字降低信任）

**建議**：改成 `BloomPath` 或 `BloomPath Inc.`

**操作**：
- App Store Connect → Users and Access → 個人 → 改 Display Name
- 或建立 Apple Developer Enterprise 帳號（成本 $99/年 → $299/年）
- 短期最快：把個人帳號顯示名改 BloomPath

3️⃣ 給星星 + 寫一兩句真實感受
